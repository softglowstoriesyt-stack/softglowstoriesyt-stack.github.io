Privacy Policy - Soft Glow Stories app

Effective date: 14 October 2026

Who uses this app

This application is used only by the owner of the Soft Glow Stories YouTube channel to manage that channel. It has no other users.

Data accessed

Through the YouTube Data API and YouTube Analytics API the app accesses only the channel's own videos, metadata, captions, playlists, comments on the channel's videos, and channel analytics reports.

How data is used

Data is used only to upload and manage the channel's own videos and to read the channel's own performance reports.

Storage

The OAuth token and working files are stored on the channel owner's private computer. No Google user data is stored on any public server.

Sharing

Data is not sold, shared with or transferred to third parties, and is not used for advertising.

Retention and deletion

Analytics exports are kept only as long as needed for channel management and can be deleted at any time. Deleting the token or revoking access stops all access immediately.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
